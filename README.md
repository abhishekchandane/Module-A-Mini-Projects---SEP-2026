# Module A Mini Projects

Each folder contains the task solution. A07, A12, A23, B08, and B19 include local preview scaffolds so their implementation files can be opened and tested. The competition starter files and media assets remain the source of truth and must replace preview assets when supplied.

For C08 and C09, start PHP with the task folder as the working directory:

```bash
php -S localhost:8000 index.php
```

Then call `/jobs` for C08, or `/rooms`, `/bookings`, and `/book` for C09.
